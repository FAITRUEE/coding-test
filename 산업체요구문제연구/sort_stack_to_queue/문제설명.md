# 스택 정렬
 
## 문제
 
stack에 저장된 숫자를 작은 수부터 큰 수 순으로 정렬하여 queue에 저장하라.
 
## 조건
 
- 외부 함수 사용 금지 (`#include`를 통한 외부 함수 사용 불가)
- 사용 가능한 함수는 아래 세 가지뿐이다
 
```c
void my_push(int s);   // stack[s]에 hold 값을 push
int  my_pop(int s);    // stack[s]에서 값을 pop하여 hold에 저장 후 반환
void enqueue(void);    // hold 값을 queue에 저장
```
 
## 환경
 
```c
#define SIZE 10000
 
static int stack[10][SIZE];  // 사용 가능한 스택 10개
static int sp[10];           // 각 스택의 스택 포인터
static int queue[SIZE];      // 결과를 저장할 큐
static int qs;               // 큐 포인터
static int hold;             // push/pop/enqueue 공유 변수
```
 
## 입력
 
- `stack[0]`에 `rand() % 1024` 범위의 정수 10000개가 저장되어 있다
- `sp[0] = 10000` (stack[0]에 10000개 적재된 상태)
- 나머지 스택은 비어있다 (`sp[1] ~ sp[9] = 0`)
 
## 출력
 
- `queue[0] ~ queue[9999]`에 오름차순으로 정렬된 값이 저장되어야 한다
 
## 성능
 
- `my_push`와 `my_pop` 호출 횟수의 합이 `SCORE`로 측정된다
- **SCORE가 낮을수록 효율적인 알고리즘이다**
- 10회 반복 실행 후 누적 SCORE를 출력한다
