# 고교 평준화 학생 배정 알고리즘

## 📌 문제

아래의 조건에 해당하는 지역에서 고교 평준화를 시행하고 있고, 이 지역에는 모두 3개의 고등학교(이하 학교)가 있다.  
내년에 학교에 입학할 중학교 3학년 학생(이하 학생)이 모두 10,000명일 때, 이 학생들을 주어진 가정과 제약 조건에 맞춰 가까운 학교로 배치하는 모듈을 작성한다.

---

## 📌 가정

1. 이 지역은 가로 세로 길이가 동일한 정사각형으로 표현되며, 좌측 상단과 우측 하단이 각각 (0,0), (999,999)로 표현된다.  
2. 학교들은 각각 0~999 사이의 정수 좌표 (x, y)에 위치하며, 동일 위치에 존재할 수 있다.  
   - 학교는 고유 번호 `school_index (0,1,2)`를 가진다.  
   - 학교는 면적이 없다.  
3. 학생들은 각각 0~999 사이의 정수 좌표 (x, y)에 거주한다.  
   - 한 좌표에 여러 명 가능  
   - 학생과 학교 위치가 같을 수 있음  
   - 학생은 `student_index (0~9999)`를 가진다.  
4. 각 학교는 최대 **3,500명**까지 수용 가능 (초과 시 패널티)  
5. 거리 계산은 **유클리드 거리(직선 거리)** 사용  
   - 예: (0,0) ↔ (1,1) → 거리 ≈ 1.414  

---

## 📌 제약 조건

1. 제공된 함수만 사용하여 데이터 접근 및 배정 수행  
2. `run_contest()` 실행 시마다 데이터는 랜덤 변경  
3. `main.c` 수정 금지, 구현은 `홍길동.c`에서만 수행  
4. 외부 라이브러리 사용 금지 (직접 구현만 허용)
